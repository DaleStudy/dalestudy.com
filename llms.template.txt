# 달레 스터디 (DaleStudy)

> 오픈 소스 프로젝트와 그룹 스터디를 통해 개발자들이 실무처럼 협업하며 성장하도록 돕는 비영리 개발자 커뮤니티. 슬로건: "평범한 개발자들이 함께 만드는 특별한 프로젝트" / "Ordinary developers building extraordinary projects".

주요 활동: 리트코드 스터디(기수제 알고리즘 스터디, GitHub PR 코드 리뷰), AI 스터디, 블로그 스터디, 독서 스터디, 달레 UI 디자인시스템(npm 패키지 daleui). 네트워킹: 커피챗(봇 자동 매칭), 모각코, 밋업.
